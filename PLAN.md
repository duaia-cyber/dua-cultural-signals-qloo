# Focused creative handoff

Profile: creator planning an event, collaboration or campaign.
Goal: move from verified cultural references to a usable team brief.

1. Collect optional project context before research; keep it local.
2. Explain reference provenance and use through expandable details, without inferred audience or booking claims.
3. Show bounded research stages from returned results; preserve errors and no-match states.
4. Add an editable selection rationale to the exported brief.
5. Collapse secondary evidence and checklist; retain clear primary actions.

Files: public/index.html, app.js, workflow.mjs, pdf-export.mjs, style.css; focused tests.
Risks: context reset, misleading provenance, export omissions, hidden keyboard controls.
Acceptance: context survives research, rationale exported in Markdown/PDF, stages reflect actual outcomes, desktop/mobile checked, isolated tests pass. No DUA account integration or inferred costs.
